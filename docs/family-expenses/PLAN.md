# Реализовать семейные расходы по этапам

План ведёт от согласования правил учёта до проверки установленной версии в Telegram и VK. ID относятся к [требованиям](REQUIREMENTS.md). Исходное состояние на 23.11.2026 — подготовлены требования и план, реализация ещё не начата.

## Выполнять шаги в worktree задачи

Следовать [порядку поэтапной разработки](../../AGENTS.md#поэтапная-разработка). После команды на выполнение основной агент закрепляет за текущим этапом одного субагента и передаёт ему worktree и критерии. Шаги ниже — основа для его разбивки. До правок основной агент проверяет шаги и рекомендации моделей. Дальше передаёт по одному шагу, проверяет результат, тесты и отдельный коммит на русском, возвращает замечания тому же исполнителю. В плане фиксировать SHA, проверки и пересмотренные рекомендации. Следующий этап начинать после приёмки предыдущего. Для push требуется явное согласие пользователя.
