# Перенос рабочих материалов в постоянную документацию

Этот список фиксирует перенос действующих решений [рабочего плана](PLAN.md)
на 29.10.2026. Постоянные документы описывают код ветки
`codex/contextual-help-implementation`; результат локальной проверки клиента
не доказывает установку этой версии на production VPS. После будущих изменений
сверяйте реестры с кодом, а перед закрытием функциональности ещё раз проверяйте
ссылки и пользовательские команды.

Постоянные файлы созданы. Точные формулировки сверяются с formatters и
обработчиками, перечисленными в каждом реестре. Клиентские пробы этапа 8
имеют границы, указанные в [результатах приёмки](STAGE8_CLIENT_RESULTS.md);
непроведённые пробы не записаны здесь как доказанное поведение клиента.

## Как отмечать выполнение

1. При изменении поведения обнови связанную строку и постоянный документ,
   затем сопоставь их с кодом и [картой кода](../CODE_MAP.md).
2. Перед закрытием задачи повторно проверь ссылки, команды и названия файлов.
   Удаление `docs/contextual-help/` выполняется отдельным завершающим
   изменением по [AGENTS.md](../../AGENTS.md#рабочий-порядок).
