Эта запись восстанавливает проверяемый маршрут PR → CI → GitHub Release для `v3.0.0` и сравнивает завершённые прогоны 30.10.2026. Практический порядок выпуска описан в [RELEASES.md](../RELEASES.md) и [OPERATIONS.md](../OPERATIONS.md); текущая работа — в [PLAN.md](PLAN.md). Данные GitHub REST API проверены 01.11.2026. Все времена ниже — UTC; снимок не подтверждает состояние VPS или будущий допуск.

## Как считать время

`Run wall-clock` = `updated_at − run_started_at` завершённого run. Это интервал workflow, включая ожидание jobs и завершающую обработку GitHub; `created_at` приведён отдельно. Для rerun используется `run_started_at` текущей attempt, а первоначальный `created_at` не считается её началом. `Job` = `completed_at − started_at` конкретной job. `Step` = `completed_at − started_at` конкретного шага. GitHub отдаёт timestamps с точностью до секунды, поэтому `0 с` означает менее одной секунды по доступным данным. Длительности steps нельзя суммировать в длительность run: между ними есть ожидание, подготовка и завершение. Поле `updated_at` используется как наблюдаемый конец run, а не как точный момент окончания последней job.

Источники: REST [workflow runs](https://docs.github.com/en/rest/actions/workflow-runs#get-a-workflow-run), [jobs и steps](https://docs.github.com/en/rest/actions/workflow-jobs#list-jobs-for-a-workflow-run), [PR](https://docs.github.com/en/rest/pulls/pulls#get-a-pull-request), [Release](https://docs.github.com/en/rest/releases/releases#get-a-release-by-tag-name) и [tag ref](https://docs.github.com/en/rest/git/refs#get-a-reference). Коннектор GitHub подтвердил связи PR и состав jobs; точные timestamps jobs/steps взяты из GitHub REST через read-only `gh api`, поскольку коннектор их не возвращает. Ссылки в таблицах ведут к конкретным объектам GitHub.

## Границы записи

- `run_attempt` взят из run API; job и step timestamps — из jobs API. Для PR #55 `pr-fast` run `41000379721` имел rerun attempt `2`: `created_at` 03:59:40, `run_started_at` attempt `2` 04:01:25, `updated_at` 04:01:37. Поэтому 1:57 от первого создания до конца второй попытки не является длительностью второй попытки. [Run](https://github.com/karateka-git/compadre-assistant/actions/runs/41000379721).
- Указанный для `pull_request` run `head_sha` — SHA head PR. Workflow делает checkout тестового merge, но его отдельный SHA не выводится в полях выбранного run; здесь он `unknown`. После merge соответствие SHA подтверждено PR API.
- GitHub Actions не содержит доказанного времени локальной подготовки, ручного выпуска, deploy на VPS или расходов Codex tokens. Для этих величин в данной записи значение `unknown`; их следует измерять отдельно.
