# Этап 8: перенос правил и сводка выпуска

Эта запись фиксирует перенос действующих правил из временных протоколов в
постоянную документацию. Итоговый сценарий и замеры находятся в
[RELEASE_REVIEW.md](../RELEASE_REVIEW.md), условия допуска — в
[RELEASES.md](../RELEASES.md), эксплуатационный порядок — в
[OPERATIONS.md](../OPERATIONS.md), состояние VPS — в
[PRODUCTION.md](../PRODUCTION.md).

## Сверить перенос

| Источник | Постоянное место | Проверяемое правило или результат |
| --- | --- | --- |
| Этапы 1 и 7, итог 7.7 | `RELEASE_REVIEW.md` | Отдельные времена CI, выпуска и простоя; исходный `deploy-prod` отказал, один forward recovery завершил v3.2.0; Codex tokens и полный счёт ручных действий неизвестны. |
| Этапы 5–7 | `RELEASES.md` | Exact SHA/run/attempt, reviewed policy, immutable Release, artifact, матрица старого SQLite API, fingerprint копии и проверка `last_good` до остановки каналов. |
| Этапы 6–7 | `RELEASES.md`, `OPERATIONS.md` | Отдельный controller snapshot, selector-aware systemd/backup, durable intent и admission, два поколения SQLite, запрет автоматического возврата на прежнюю БД после admission. |
| Инцидент и recovery 7.7 | `OPERATIONS.md`, `PRODUCTION.md`, `RELEASE_REVIEW.md` | `python3 -P`, приватный GitHub read token, узкий forward recovery на тех же ID и выбранной БД; отсутствие reboot/power-loss испытаний. |
| Отмена PR #78 | `PRODUCTION.md`, `RELEASES.md`, `OPERATIONS.md` | CI baseline v3.1.0 не совпадает с установленной v3.2.0; следующий deploy закрыт без отдельного exact-pair допуска. |
| Перенесённая дальнейшая работа | `BACKLOG.md` | Автоматическая ротация базы CI, подробный разбор verifier, измерения будущих выпусков, испытания автоматического recovery и срок хранения старых SQLite остаются открытыми. |

В постоянных документах убраны ссылки на `docs/ci-release-review/`; README
ведёт к текущему снимку VPS и новой сводке. Исторические измерения не
представлены как доказательство нынешнего состояния сервера. Перенос не
меняет VPS, рабочую БД, GitHub variable или CI policy.

## Сохранить временный каталог до завершения функциональности

У исходного пункта [«Разобрать CI и выпуск вместе с создателем»](../BACKLOG.md#разобрать-ci-и-выпуск-вместе-с-создателем)
доступные результаты и границы измерений зафиксированы. Полный исторический
учёт ручных действий и Codex tokens недоступен; будущие замеры и испытания
автоматического recovery теперь входят в задачу сопровождения. По `AGENTS.md`
временный каталог удаляется отдельным завершающим изменением после проверки
полноты переноса. До этого исходный пункт бэклога не закрыт. Задача
сопровождения остаётся открытой после закрытия этого пункта.
