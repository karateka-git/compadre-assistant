## Новое

В Telegram и VK появились команды `/capabilities`, `/enable <id>` и
`/disable <id>`. Они меняют личный набор Ask и Obsidian для одного профиля;
связанные каналы видят общий выбор. `/capabilities` показывает личное
состояние и доступность возможности на сервере.

Ask выбран по умолчанию, если он разрешён сервером и настроен его провайдер.
Obsidian по умолчанию выключен и включается командой `/enable obsidian`.
Это относится и к существующим профилям без явной настройки. Сохранённые
режимы, статьи и vault не удаляются: после включения Obsidian прежний режим
снова доступен. `/disable` не заменяет `/exit`, который очищает режим
текущего чата.

Новая миграция `0002_user_capability_preferences.sql` сохраняет личный
выбор. Она применяется поверх прежней `0001_initial_schema.sql` без
пересоздания production-БД. Уже начатый долгий ответ может прийти в исходный
чат после отключения возможности; новые обращения получат отказ.

## Перед установкой

Для живой работы Ask сервер должен включать `ask` в
`ENABLED_CAPABILITIES` и иметь валидные `ASK_*`. Личное `/enable` не обходит
серверное отключение. Установка и миграция проходят только через обычный
контроллер выпуска с проверенным backup, схемой и обоими каналами.
