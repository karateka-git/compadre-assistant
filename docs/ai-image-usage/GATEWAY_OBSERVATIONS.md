# Результаты проверки Timeweb AI Gateway

Здесь фиксируются наблюдения по [плану проверки](GATEWAY_PLAN.md). Они нужны
для адаптера извлечения текста и расчёта стоимости обращений.

## 1. Подготовка локальной проверки

Документация Timeweb проверена 13.11.2026. Базовый URL шлюза
`https://api.timeweb.ai/v1`, метод `POST /v1/chat/completions`. Действующий
адаптер Ask использует тот же метод OpenAI SDK `chat.completions.create`.
Проверочная модель `gemini/gemini-3.1-flash-lite`. При переключении на резервную
модель поле `model` в ответе может отличаться от отправленного идентификатора.
[Подключение к шлюзу](https://timeweb.cloud/docs/ai-gateway/manage) ·
[Резервные модели](https://timeweb.cloud/docs/ai-gateway/fallback).

Для пробы изображения подготовлен запрос Chat Completions с двумя частями
`messages[0].content` для сообщения с ролью `user`. Первая часть `type: text`
просит вернуть текст с изображения с сохранением переносов. Вторая часть
`type: image_url` передаёт байты PNG как `data:image/png;base64,…` в
`image_url.url`. Формат описан в спецификации OpenAI. Поддержку этого формата
на выбранной модели через Timeweb подтвердит запрос на шаге 3.
[Спецификация Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).

В текущем worktree локальный `.env` отсутствует. В `.env` основной рабочей
папки `ASK_API_KEY` не задан, `OPENAI_API_KEY` задан, а `OPENAI_BASE_URL` после
нормализации завершающего слеша совпадает с официальным URL Timeweb.
Для контрольных запросов доступен этот локальный ключ. Его действительность
и доступ к модели проверяются на шаге 2. Ключ используется для запроса к
официальному endpoint Timeweb и остаётся в локальных настройках.

[Контрольное изображение](gateway-ocr-sample.png) — синтетический PNG
`480 × 168` с кириллицей, цифрами и английским словом. Ожидаемый текст:

```text
Тест OCR
Код 8415
Finish
```

Для текстовой пробы отправить вопрос «Сколько будет 16 + 27? Ответь только
числом.» и ожидать `43`. Поля ответа, работа с изображением и тарифы
проверяются на следующих шагах.

## 2. Текстовый запрос

13.11.2026 с `15:37:17` до `15:37:18` UTC один текстовый запрос к
`POST https://api.timeweb.ai/v1/chat/completions` с моделью
`gemini/gemini-3.1-flash-lite` вернул HTTP 200. Для вызова установлен таймаут
30 секунд. Автоматические повторы и перенаправления не использовались.

Поле `model` совпало с запрошенной моделью. `choices[0].message.content`
после удаления крайних пробелов совпало с `43`, а
`choices[0].finish_reason` было равно `stop`.

В ответе было поле `id`. Отдельного идентификатора запроса или корреляции в
HTTP-заголовках не наблюдалось. Полный `id` сохранён локально вне репозитория
для проверки журнала на шаге 4. Возможность поиска по этому полю пока не
проверена.

| Поле `usage` | Значение |
| --- | ---: |
| `prompt_tokens` | 19 |
| `completion_tokens` | 2 |
| `total_tokens` | 21 |
| `prompt_tokens_details.text_tokens` | 19 |
| `completion_tokens_details.text_tokens` | 2 |

В этом ответе детали содержали только `text_tokens`. Поля кэшированных и
reasoning-токенов отсутствовали, поэтому проба не устанавливает их значения
или правила тарификации.

## 3. Запрос с изображением

13.11.2026 с `15:38:34` до `15:38:36` UTC один запрос к тому же endpoint и
модели вернул HTTP 200. Использован контрольный PNG из шага 1. В `content`
переданы текстовая инструкция и `image_url.url` с `data:image/png;base64,…`.
Таймаут составил 30 секунд. Автоматические повторы и перенаправления не
использовались.

Поле `model` совпало с текстовой пробой. `choices[0].message.content` после
удаления крайних пробелов и нормализации CRLF до LF точно совпало с тремя
ожидаемыми строками в исходном порядке. `choices[0].finish_reason` было равно
`stop`. Как в текстовой пробе, присутствовало поле `id`, а отдельного
идентификатора запроса или корреляции в HTTP-заголовках не наблюдалось. Полный
`id` сохранён локально вне репозитория для сверки на шаге 4.

| Поле `usage` | Текст | Изображение с инструкцией |
| --- | ---: | ---: |
| `prompt_tokens` | 19 | 1088 |
| `completion_tokens` | 2 | 13 |
| `total_tokens` | 21 | 1101 |
| `prompt_tokens_details.text_tokens` | 19 | 24 |
| `prompt_tokens_details.image_tokens` | Поле отсутствует | 1064 |
| `completion_tokens_details.text_tokens` | 2 | 13 |

В пробе с изображением `prompt_tokens` равнялось сумме наблюдавшихся
`text_tokens` и `image_tokens`. Поля кэшированных и reasoning-токенов
отсутствовали. Наблюдение подтверждает приём PNG в указанном формате и форму
этого ответа. Правила тарификации предстоит уточнить на шаге 4.
