# Отчёт в режиме администрирования

Этот реестр описывает вход `/admin`, расчётный отчёт `/llm_costs` и ответы при
ошибке. Порядок действий приведён в [RUN.md](../RUN.md#посмотреть-расходы-ии),
права профиля описаны в [настройке](../SETUP.md#настроить-режим-администрирования).

## Войти в режим администрирования

После `/admin` в личном чате бот отвечает «Режим администрирования включён.
Чтобы получить отчёт, вызови `/llm_costs`. Для выхода вызови `/exit`.»
Действие «Показать расходы ИИ» отправляет `/llm_costs` с обычной повторной
проверкой допуска. Режим относится к чату, в котором отправлена команда входа.

Если передать аргумент, бот отвечает «Используй `/admin` без аргументов» и
сохраняет прежний режим чата. Доверенному профилю при входе из группы бот
отвечает «Режим администрирования включён. Открой личный чат с ботом, чтобы
получить отчёт» без кнопки. Если у профиля нет права, ядро отклоняет вход и
команды режима. [Условия отказов](CORE.md#посмотреть-профиль-выбрать-возможность-и-режим).

## Получить отчёт

В активном `/admin` отправь `/llm_costs` в личном чате. Бот показывает
«Расчётные расходы ИИ», выбранный IANA-пояс и три строки с расчётной суммой
и количеством запросов без оценки. Для пустой истории значения равны нулю.
Пример отчёта с разными итогами по периодам:

```text
Расчётные расходы ИИ
Часовой пояс Asia/Omsk

Сегодня — 0,00 ₽. Запросов без оценки — 0.
Текущий месяц — 0,13 ₽. Запросов без оценки — 1.
Текущий год — 1,26 ₽. Запросов без оценки — 2.
```

`/llm_costs Europe/Moscow` меняет пояс для одного отчёта. При неизвестном
поясе бот отвечает «Часовой пояс не найден. Используй название IANA,
например `/llm_costs Europe/Moscow`». При нескольких аргументах отвечает
«Укажи один часовой пояс. Например, `/llm_costs Europe/Moscow`».

Если чтение не удалось, бот отвечает «Отчёт временно недоступен. Повтори
`/llm_costs` позже». В группе бот отвечает «Открой личный чат с ботом, чтобы
получить отчёт» до попытки чтения. Обычный текст в активном режиме в личном
чате получает подсказку «Чтобы получить отчёт, вызови `/llm_costs`».
Режим сохраняется после результата, отказа или подсказки. `/exit` завершает
режим текущего чата.
