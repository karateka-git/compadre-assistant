# Отчёт в режиме администрирования

Этот реестр описывает вход `/admin`, отчёт Timeweb `/llm_costs` и ответы при
ошибке. Порядок действий приведён в [RUN.md](../RUN.md#посмотреть-расходы-ии),
права профиля описаны в [настройке](../SETUP.md#настроить-режим-администрирования).

## Войти в режим администрирования

После `/admin` в личном чате бот отвечает «Режим администрирования включён.
Чтобы получить отчёт, вызови `/llm_costs`. Для выхода вызови `/exit`.»
Действие «Показать расходы ИИ» отправляет `/llm_costs` с обычной повторной
проверкой допуска. Режим относится к чату, в котором отправлена команда входа.

Если передать аргумент в личном чате, бот отвечает «Используй `/admin` без
аргументов» и сохраняет прежний режим чата. Если команда входа пришла вне
личного чата, бот отвечает «Открой личный чат с ботом, чтобы
получить отчёт». Если у профиля нет права, ядро отклоняет вход и команды
режима. [Условия отказов](CORE.md#посмотреть-профиль-выбрать-возможность-и-режим).

## Получить отчёт

В активном `/admin` отправь `/llm_costs` в личном чате. Бот показывает сводку
с выбранным поясом, валютой аккаунта и суммами до списания бонусов.
Пример ответа с подтверждённым нулём, частичным итогом и годом за пределами
доступной истории:

```text
Расходы ИИ по статистике Timeweb
Часовой пояс Asia/Omsk
Валюта RUB. Суммы до списания бонусов.

Сегодня — 0,00 ₽. Запросов: 0.
Текущий месяц — Известная сумма 0,13 ₽. Интервалов без стоимости — 1. Запросов: 4.
Текущий год — Полный период недоступен.
```

`/llm_costs DAY`, `/llm_costs MONTH` и `/llm_costs YEAR` выбирают один период.
`/llm_costs Europe/Moscow` меняет пояс сводки, а
`/llm_costs DAY Europe/Moscow` выбирает сутки в указанном поясе.
При неизвестном поясе бот отвечает «Часовой пояс не найден. Используй
название IANA, например `/llm_costs Europe/Moscow`.» При неверной
последовательности аргументов бот предлагает «Укажи период DAY, MONTH или
YEAR, затем при необходимости часовой пояс. Например, `/llm_costs DAY Europe/Moscow`.»

Без настроенного источника бот отвечает «Статистика Timeweb не настроена.»
При ошибке чтения стоимости в строке периода показано «Статистика Timeweb
временно недоступна.» Если число запросов подтверждено, строка также его
показывает. Если стоимость доступна, а счётчик недоступен, строка заканчивается
текстом «Число запросов недоступно.» Другие строки сводки сохраняются.
Обычный текст в активном режиме получает подсказку
«Чтобы получить отчёт, вызови `/llm_costs`.»
`/exit` завершает режим текущего чата.
